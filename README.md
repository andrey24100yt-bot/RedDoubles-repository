# RedDoubles-repository
# Лабораторная работа №1

Принцип работы:
извлечение сущностей → очистка → обезличивание → токенизация → удаление стоп-слов → лемматизация → частотный анализ.

---
Возможности
- Автоматическое определение текстовой колонки в CSV
- Извлечение URL, e-mail, телефонов, дат и цен через регулярные выражения
- Обезличивание персональных данных маркерами `[URL]`, `[EMAIL]`, `[PHONE]`, `[PRICE]`, `[DATE]`
- Токенизация и удаление стоп-слов через `sklearn.CountVectorizer`
- Автоматическое построение списка стоп-слов из базы (топ-N частых + короткие слова)
- Автоматическое извлечение окончаний из базы для лемматизации
- Собственный стеммер без внешних словарей
- Частотный анализ: TOP-20 слов до/после очистки + TOP-20 лемм
- Сохранение результата в `clean_messages.csv`
---
